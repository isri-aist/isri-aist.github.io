# 自動運転移動サービス社会実装コンソーシアム

## 目的

レベル4自動運転の実証が進む一方、持続可能な移動サービスとしての社会実装には、乗客サービス、運行管理、事業性、許認可など、事業者を横断する課題が残されています。

**自動運転移動サービス社会実装コンソーシアム**は、研究者・開発者、運行事業者、自治体、産業界・学界が集まり、協調領域の課題・制約・障壁を共有し、**技術・運用・法制度**の各面から解決に取り組む場です。

目指す姿は、**公共交通の社会課題の解決、関連産業の振興、安心・安全で快適な移動社会の実現**です。

## 設置の背景

産総研は、経済産業省・国土交通省の連携プロジェクト **「RoAD to the L4」**（2021～2025年度）において総合調整を担い、福井県永平寺町、茨城県日立市のひたちBRT、千葉県柏の葉などの社会実装に関する取組を進めてきました。

今後は、その実績と知見を活用し、個別の技術実証にとどまらず、事業者・自治体・研究機関が共通して直面する課題を協調して解決することを目指します。

## 主な活動

| 活動 | 内容 |
| --- | --- |
| **交流事業** | 国内外の最新動向の調査、情報共有・交換 |
| **課題解決支援** | 課題の協議、検証データ・実証評価の提供 |
| **プロジェクト支援** | プロジェクト等の立案・推進 |
| **普及啓発** | シンポジウムやWebを通じた情報発信・啓発 |
| **その他** | 目的達成に必要な事業 |

### 検討する課題の例

- **自動運転バスの立席実現**：乗客サービスと安全性の両立
- **遠隔監視運用**：少人数による複数車両の運行管理
- **運行・事業性**：持続可能な運行体制と実装コストの低減
- **制度・許認可**：関係者間での課題共有と対応策の検討

これらは検討テーマの例です。

## 運営体制

総会、運営委員会、事務局、ワーキンググループ（WG）を基本とする運営体制です。個別の役員やWGの詳細は、確定した情報に応じて更新します。

## 期待される成果

- 自動運転移動サービスの**社会実装の加速**
- 知見・データの共有による**実装コストの低減**
- 制度面の課題整理と**制度整備等の促進**
- 共同研究・実証を通じた**研究開発・事業創出**
- 産学官連携による地域交通の維持・発展への貢献
